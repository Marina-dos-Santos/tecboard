## Tecboard | Aplicativo para monitoramento de sistemas 📊
Página de apresentação do Tecboard, um aplicativo para monitorar aplicações em tempo real e enviar alertas inteligentes, para que elas nunca saiam do ar sem você saber.

🔗 [Acesse o site](https://marina-dos-santos.github.io/tecboard/)

## Sobre o projeto📌
O Tecboard é uma landing page criada para apresentar o conceito de um app de monitoramento de sistemas. A página destaca a proposta de valor do produto ("Fique de olho no que importa") e mostra a interface do aplicativo em dispositivos móveis.
O projeto foi desenvolvido do zero, com foco em um layout limpo e responsivo.

## Tecnologias utilizadas🛠️
HTML5: estrutura da página <br>
CSS3: estilização e responsividade<br>
GitHub Pages: hospedagem
